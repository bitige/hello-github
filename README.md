## 每天的常用命令

| 命令 | 作用 |
| --- | --- |
| `git status` | 看当前有哪些改动 |
| `git add .` | 把所有改动加入待提交 |
| `git commit -m "说明"` | 打一个存档点 |
| `git push` | 上传到 GitHub |
| `git pull` | 拉取远程的改动 |
| `git log --oneline` | 查看提交历史 |
| `git diff` | 看具体改了哪几行 |
